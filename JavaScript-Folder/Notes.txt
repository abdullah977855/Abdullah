Array Method:

push(): Adds one or more elements to the end of the array. Returns the new length.
pop(): Removes the last element from the array. Returns that removed element.
unshift(): Adds one or more elements to the start of the array. Returns the new length.
shift(): Removes the first element from the array. Returns that removed element.
splice(): Adds, removes, or replaces elements at any specific index. Returns an array of deleted items.
indexOf(): Check element present in array : return index number.
include(): Check Element present in array: return the true or false.

String Methods:

toUpperCase(): Poore text ko BADE LETTERS (Capital) mein convert karta hai
toLowerCase(): Poore text ko chhote letters (Small) mein convert karta hai
indexOf(substring, start): Kisi character ya word ki pehli position (index) batata hai. Agar na mile toh -1 deta hai.
slice(start, end): Text ka ek hissa kaat kar nikalta hai. Is mein aap ulte numbers (negative index jise -1) bhi de sakte hain jo peeche se counting karte hain.
lastIndexOf(substring, start): Kisi word ki aakhri position batata hai agar woh text mein baar baar aa raha ho.
charAt(index): Diye gaye index par kaun sa single letter maujood hai, woh batata hai.
charCodeAt(index): Us position par maujood character ka Unicode (UTF-16) number batata hai

Math Methods:

.random() : 0 sy lekr 0.99 tk koi bhi number dyga.
.round() : Yeh method check karta hai ke aapka number kis integer ke zyada kareeb (closest) hai.
Agar point ke baad .5 ya us se bara number ho toh yeh uoper le jata hai.
Agar point ke baad .5 se chota number ho toh yeh neeche le jata hai.
Exact darmiyan me hai toh rule ke mutabiq uoper jayega
.ceil(): Yeh method point ke baad kuch bhi ho, number ko hamesha agley (uoper wale) poore number par phenk deta hai.
.floor(): Point ke baad chahe jitna bara number ho (jaise .99), yeh usko hamesha pichle (neeche wale) poore number par gira deta hai.
.trunc(): Ye point (.) ke baad jitne bhi numbers hain, unko direct delete kar deta hai.Positive numbers mein Math.floor aur Math.trunc bilkul ek jaisa kaam karte hain, lekin Minus (Negative) numbers mein inka farq samajh aata hai:
Math.pow(base, exponent): Kisi number ki power nikalne ke liye. (Note: Aaj kal modern JS mein power ke liye ** operator bhi use hota hai).
Math.sqrt(x): Kisi number ka Square Root nikalta hai.
Math.cbrt(x): Kisi number ka Cube Root nikalta hai.
Math.abs(x): Minus (-) sign ko khatam karke hamesha positive value deta hai.
Math.min(a, b, c...): Diye gaye numbers mein se sab se chota number nikalta hai.
Math.max(a, b, c...): Diye gaye numbers mein se sab se bara number nikalta hai.
Math.PI: Circle ki Pi value (~3.14159).
Math.E: Euler's number (~2.718).
Math.sign(x): Number ka sign batata hai: positive ho to 1, negative ho to -1, aur zero ho to 0 deta hai.
Math.hypot(a, b...): Saare numbers ke squares ka sum karke uska square root nikalta hai (Pythagoras theorem ke liye best hai: \(\sqrt{a^{2}+b^{2}}\)).
Math.exp(x): Yeh method \(e^{x}\) ki value nikalta hai. Yaani Euler's number (\(2.718\)) ko \(x\) baar multiply karta hai.

Date Object:
avaScript mein Date object date aur time ke sath kaam karne ke liye istemal hota hai. Iske methods ko hum 4 main categories mein divide kar sakte hain: Get methods (time nikalne ke liye), Set methods (time badalny ke liye), Formatting methods (text mein convert karne ke liye), aur UTC methods (world time ke liye).


Date Methods:
getFullYear(): Ye aapko mukammal saal (Year) deta hai (jaise 2026).
getMonth(): Ye mahina (Month) deta hai. Yaad rahe yeh 0 se 11 tak counting karta hai (0 ka matlab January aur 11 ka matlab December hai).
getDate(): Ye mahine ki tareekh (Day of the month) deta hai (1 se 31 tak).
getDay(): Ye hafte ka din (Day of the week) deta hai. Ye bhi 0 se 6 tak hota hai (0 ka matlab Sunday aur 6 ka matlab Saturday hai).
getHours(): Ye ghante (Hours) deta hai (0 se 23 tak).
getMinutes(): Ye minutes deta hai (0 se 59 tak).
getSeconds(): Ye seconds deta hai (0 se 59 tak).
getMilliseconds(): Ye milliseconds deta hai (0 se 999 tak).


DOM:
Document Method:
document.write('text/html')Kaam: Direct browser window par kuch bhi likhne ya HTML content insert karne ke liye (zyadatar testing ke liye use hota hai).
document.getElementById('id')Kya target karta hai: Kisi specific ID wale element ko. Kya return karta hai: Sirf ek element object.
document.querySelector('selector')Kya target karta hai: CSS selector (id, class, ya tag) ke mutabik sab se pehle aane wale element ko.Kya return karta hai: Sirf ek element object.
document.querySelectorAll('selector')Kya target karta hai: CSS selector se match hone wale saare elements ko.Kya return karta hai: Ek NodeList (ye array jaisa hota hai jis par aap forEach loop chala sakte hain).
document.getElementsByClassName('class-name')Kya target karta hai: Us class name wale saare elements ko.Kya return karta hai: Ek HTMLCollection (elements ka collection).
document.getElementsByTagName('tag-name')Kya target karta hai: Us HTML tag (jaise p, div, button) wale saare elements ko.Kya return karta hai: Ek HTMLCollection (elements ka collection).
document.createTextNode()Kya banata hai: Yeh sirf sada text banata hai (jaise "Hello World"). Iska koi HTML tag nahi hota.Umeed: Is par aap koi style, id, ya class direct apply nahi kar sakte kyunki yeh koi HTML tag nahi hai.Asaan misal: Yeh us dabbe ke andar rakhne wala samaan hai.
document.addEventListener('event', function)Kaam: Pure document par koi event (jaise DOMContentLoaded ya click) sunne aur uspar action lene ke liye use hota hai.
.createElement("tagName"): Kaam: Ek naya HTML element (jaise div, p, button) memory me create karta hai.

DOM Insertion:
appendChild(): sirf ek waqt me ek hi HTML element ko insert karta hai aur text par error deta hai.
append(): ek sath multiple elements aur plain text dono ko insert kar sakta hai
prepend(): Kya karta hai: Yeh aapke naye element ko kisi parent element ke sabse shuru me (start par) jod deta hai.Syntax: parent.prepend(newElement);
before(): Kya karta hai: Yeh naye element ko target element ke theek pehle (outside, uske upar) insert karta hai. Yaani yeh use sibling (bhai) bana deta hai, child nahi.Syntax: targetElement.before(newElement);
after(): Kya karta hai: Yeh naye element ko target element ke theek baad (outside, uske neeche) insert karta hai.Syntax: targetElement.after(newElement);
insertAdjacentHTML(): (Sabse Fast aur Powerful Method)Yeh method element banane aur insert karne ka kaam ek sath kar deta hai. Isme aapko alag se createElement ya innerText nahi likhna parta, balki aap direct HTML ki string likh dete hain.Iske paas 4 positions hoti hain:beforebegin: Target element ke theek pehle (bilkul before() ki tarah).afterbegin: Target element ke andar, sabse shuru me (bilkul prepend() ki tarah).beforeend: Target element ke andar, sabse aakhri me (bilkul append() ki tarah).afterend: Target element ke theek baad (bilkul after() ki tarah).

Events:
click: 	Jab user kisi element par (jaise button ya link) click karta hai.
dblclick: Jab user short time mein do (2) baar click karta hai.
mousedown: 	Jab user mouse ka button niche dabata hai (click mukammal hone se pehle).
mouseup: Jab user mouse ka dabaya hua button chhorta (release) hai.
contextmenu: Jab user right-click karta hai (menu khulne se pehle).
keydown: Jab keyboard ki koi bhi key dabai jati hai (chahe woh letter ho, Shift ho ya Enter).
keyup: Jab user dabai hui key ko chhorta (release) hai.
focus: Jab user kisi input box ke andar click karta hai (field active hoti hai).
input: Jab user input box mein kuch bhi type ya delete karta hai (har ek character par).
change: Jab user value badal kar box se bahar click kare, ya dropdown mein koi naya option select kare.
blur: Jab user input box se bahar kahin bhi click kar de (chahe value badli ho ya na badli ho).
submit: Jab user pure form ka data bhejne ke liye Submit button dabaye ya Enter press kare.
DOMContentLoaded: Sirf HTML ready hone par chalta hai (Tezi se kaam shuru karne ke liye). document object pr lgta hy.
load: Har cheez (Images) load hone ke baad chalta hai (Loader hatane ke liye). window object pr lgta hy.
scroll: Page ko upar/neeche move karne par chalta hai (Sticky header ya scroll effects ke liye).window object pr lgta hy.
resize: Screen ka size badalne par chalta hai (Responsive adjustments ke liye).window object pr lgta hy.
